# 更改日志

**中文** · [English](CHANGELOG_en.md)

## v0.1.2

### 🤨更新内容

- 添加播放进度共享功能. 支持 Original + Pitch / Adjusted 两档时间发布格式设置. 默认 Original + Pitch 共享原始时间轴与实际播放速率; Adjusted 共享随速度折算的时间轴, 速率保持 1. 持续查询实际进度, 正常推进时不重复发布; 状态或时间轴变化时更新, 位置偏差超过 100 ms 时校正.
- 添加播放位置控制功能, 支持通过 SMTC 请求跳转, 保持播放或暂停状态.
- 添加封面, 曲目信息, 播放进度和播放位置控制开关. 当前共五项开关, 按总开关, 封面, 信息, 进度, 位置控制的顺序排列, 默认全部启用.
- 添加每约 5 秒的进度日志汇总, 记录查询, 发布尝试及更新原因.

## v0.1.1

### 🤨更新内容

- 封面宽高限制调整为 5000 × 5000 像素, 文件大小上限调整为 10 MB.
- 网络封面最多允许 1 次重定向, 各阶段超时调整为 1 秒, 下载总等待期限调整为 5 秒.
- 为 Windows 异步操作添加超时与停止响应, 避免长时间等待影响媒体控制和插件停用.
